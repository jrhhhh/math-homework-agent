## 二、逐题问题位置、依据与最小修改

### 第 3 题（单选）· 结论错误

- **问题位置**：无法定位。学生只提交了选项 `C`，没有过程；按同伴规则，
  **只有答案时仅核验结论，不推测"为什么"**。
- **依据**：`a·b = 2×1 + 1×m = 2 + m`；`a ⊥ b ⟺ a·b = 0 ⟹ m = −2`，正确选项为 **A**。
  学生所选 `C`（−1/2）使 `a·b = 3/2 ≠ 0`，故结论错误。
- **最小修改**：写出 `a·b = 2 + m = 0`，得 `m = −2`（选 A）。

### 第 8 题（单选）· 结论错误

- **问题位置**：无法定位（同上，仅有选项 `C`）。
- **依据**：`f(x) = 2^x − 2^(−x)`。对任意 `x1 < x2`，
  `f(x2) − f(x1) = (2^(x2) − 2^(x1)) + (2^(−x1) − 2^(−x2)) > 0`（两项都为正），
  故在 **R** 上单调递增；也可用 `f'(x) = (2^x + 2^(−x))ln2 > 0`。正确选项为 **A**。
  学生所选的"在 (0,+∞) 递减"不成立（例如 `f(1) = 3/2 > f(0) = 0`）。
- **最小修改**：改用差值法或求导判定符号，得"A. 在 R 上单调递增"。

### 第 10 题（多选）· 结论不完整

- **问题位置**：结论层：选项集合 `ABD` 漏掉成立的一支 `C`（仅有选项，无逐项判断过程）。
- **依据**：`a² = 4, b² = 12, c² = 16`，故 `c = 4`，焦点在 x 轴（A 真）、`e = c/a = 2`（B 真）、
  渐近线 `y = ±(b/a)x = ±√3 x`（**C 真**）、实轴长 `2a = 4`（D 真）⟹ 答案 **ABCD**。
- **最小修改**：补一句渐近线公式 `y = ±(b/a)x` 的代入计算，把 C 勾上。
  （按卷面自带规则"部分选对得 2 分"，该题只拿到 2 分。）

### 第 11 题（多选）· 结论不完整

- **问题位置**：结论层：选项集合 `ABC` 漏掉成立的一支 `D`。
- **依据**：`a > 0, b > 0, a + b = 4`。
  A：`ab ≤ ((a+b)/2)² = 4`；B：`1/a + 1/b = (a+b)/ab = 4/ab ≥ 1`；
  C：`a² + b² = 16 − 2ab ≥ 8`；
  **D**：`(√a + √b)² = a + b + 2√(ab) = 4 + 2√(ab) ≤ 8`，故 `√a + √b ≤ 2√2`
  （`a = b = 2` 时取等）⟹ 答案 **ABCD**。
- **最小修改**：把 D 的平方展开写出来再比较，别只凭"看起来偏大"排除。

### 第 21(2) 题 · 论证缺口（首错位置：并列式之后的"合并"这一步缺失）

- **问题位置**：从"`y1y2 = (kx1+m)(kx2+m) = k²x1x2 + km(x1+x2) + m²`"到
  "由 `OA ⊥ OB` 得 `x1x2 + y1y2 = 0`"之间：**已设好的两条式子没有合并，也没有给出 m 的范围**。
  另有一个未核验的前提：使用韦达定理前**没有核验判别式 Δ > 0**。
- **依据（局部重算）**：
  - `x1 + x2 = −8km/(1+4k²)`、`x1x2 = (4m²−8)/(1+4k²)` 与学生的写法一致（同学段重算通过）；
  - `y1y2 = (m² − 8k²)/(1+4k²)`；
  - `x1x2 + y1y2 = (5m² − 8 − 8k²)/(1+4k²) = 0` ⟹ `8k² = 5m² − 8 ≥ 0` ⟹ `m² ≥ 8/5`；
  - 判别式：`Δ = 64k²m² − 4(1+4k²)(4m²−8) = 16(8k² − m² + 2)`，代入 `8k² = 5m² − 8`
    得 `Δ = 16(4m² − 6) > 0`（因 `m² ≥ 8/5 > 3/2`），即"交于两点"自动满足；
  - 独立核对：弦 `AB` 对中心张直角时，中心到直线的距离 `d` 满足 `d² = a²b²/(a²+b²) = 8/5`，
    而 `d² = m²/(1+k²)` ⟹ `m² = (8/5)(1+k²) ≥ 8/5`，与上面一致。
- **最小修改**（补两行，其余照抄学生的）：
  1. `x1x2 + y1y2 = [(4m²−8) + (m²−8k²)]/(1+4k²) = (5m²−8−8k²)/(1+4k²) = 0`
     ⟹ `8k² = 5m² − 8 ≥ 0` ⟹ `m² ≥ 8/5`；
  2. 补一句"此时 `Δ = 16(4m²−6) > 0`，直线与椭圆确有两个交点"。
- **订正结论**：`m ∈ (−∞, −2√10/5] ∪ [2√10/5, +∞)`。

### 第 22(1) 题 · 论证缺口（首错位置：`x = e^(a−1)` 之后的符号讨论缺失）

- **问题位置**：求出驻点 `x = e^(a−1)` 之后直接停笔，**没有讨论 `f'` 在该点两侧的符号**，
  因而没有写出单调区间。定义域 `(0,+∞)` 与求导 `f'(x) = ln x + 1 − a` 两步都成立。
- **依据（局部重算）**：`f'(x) = ln x + 1 − a = 0 ⟺ ln x = a − 1 ⟺ x = e^(a−1)`；
  `x = e^(a−1) > 0` 恒在定义域内（对任意 `a ∈ R` 都成立，**不需要分类讨论**）；
  `x < e^(a−1)` 时 `f'(x) < 0`，`x > e^(a−1)` 时 `f'(x) > 0`。
- **最小修改**（补三行）：
  1. 当 `0 < x < e^(a−1)` 时 `f'(x) < 0`；
  2. 当 `x > e^(a−1)` 时 `f'(x) > 0`；
  3. 结论：单调递减区间 `(0, e^(a−1))`，单调递增区间 `(e^(a−1), +∞)`。
