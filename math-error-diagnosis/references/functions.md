# 函数、导数与代数审查

- 先明确函数定义域及题目指定区间；分式、偶次根式、对数及复合函数的限制应取交集。变形后仍保留原定义域。
- 求导式只在相应可导范围内使用；分段点需分别检查连续、可导或按原定义比较，不套用单段公式。
- f'(x)>0 在区间内可推出严格递增，但严格递增不必处处 f'(x)>0，例如 f(x)=x³。f'≥0 在可导区间可推非减，不能单凭此推出严格递增；需排除任何子区间上恒为零等情况。教材“增函数”的定义以所给教材为准。
- f'(x0)=0 不能单独推出极值；用两侧符号或其他合法依据检查。极值点与闭区间最值点不同，闭区间求最值还需比较端点；开放区间上的上界不一定取到。
- 单调区间应按定义域断点和导数符号分开。两个分离区间各自递增不能直接合并为整体递增。
- 恒成立参数题明确“对所有 x”与“存在 x”；变量与参数角色不能互换。除以参数或含变量表达式时分类，临界参数单独回代。
- 基本不等式检查所用版本的非负或正数条件（a+b≥2√(ab)允许a,b≥0）、和或积是否固定、等号条件能否同时成立；形式上的下界未必可达。
- 零点存在使用连续性等充分条件；端点同号不能直接断言无零点，异号也不保证唯一。唯一性需另给单调性等依据。
- 对数底数须正且不为1，真数正；底数在(0,1)时单调方向不同。指数与幂函数注意数域和奇偶性。
- 参数二次方程先检查二次项系数是否为零，再用判别式；候选解须满足原方程和附加条件。
