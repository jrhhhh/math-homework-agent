# 圆锥曲线与平面解析几何审查

- 对椭圆先确定长轴方向，通常a为长半轴且a>b>0，c²=a²-b²；双曲线a为实半轴、b为虚半轴，c²=a²+b²，不要求a>b。离心率椭圆0<e<1，双曲线e>1；圆的特殊情形按题意处理。
- 标准方程的坐标方向对应焦点和顶点，不能只取分母较大者确定双曲线实轴。
- 对抛物线 y²=2px（p>0）焦点为(p/2,0)、准线x=-p/2；若题用y²=4ax则焦点为(a,0)。先识别参数约定再代公式。
- 设直线 y=kx+b 会遗漏竖直直线。若题设尚未排除竖直情形，分开检查或用一般式/参数式；不因使用斜截式本身就判错，先看是否已覆盖其余情形。
- 联立消元后检查二次项系数；为零时退化为一次方程或其他情形，不能继续用二次判别式、韦达和二次根公式。
- 在真正的二次方程及等价消元条件下，Δ>0对应两个不同实根；Δ=0只有重根，弦端点要求不同则需排除。清分母、平方或参数化引入的候选根还需回代原方程。
- 韦达只提供和积关系，不能自动保证两个交点真实存在或满足几何限制。点差法也要保留交点不同、所除坐标差非零等条件。
- 面積、弦长、距离须非负；弦长公式中根差取绝对值。用斜率乘积判垂直须两条斜率存在；竖直/水平情形另查。
- 轨迹题先证明必要性，再检查充分性，排除不允许的点；定点/定值命题须对全部允许参数成立。根为实数不自动保证点在指定支、线段或射线上。
- 圆锥曲线参数临界值、焦点重合、切线代替割线、点重合等退化情形以原题条件判定是否允许。
