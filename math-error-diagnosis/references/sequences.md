# 数列与求和审查

- 明确n从1还是0开始，递推式适用n≥1还是n≥2；通项须满足首项以及每一步递推。
- a_n=S_n-S_(n-1)通常对n≥2使用，a_1=S_1另查；若明确S_0=0且同一公式在0也成立，才可统一。
- 证明等差需相邻差恒定，证明等比需满足题设/教材的公比定义与零项约定；除以a_n或构造倒数、比值前检查零项。只检查前几项不是证明。
- 等差求和核对项数、首末项与指标。等比求和q≠1时为a_1(1-q^n)/(1-q)，q=1时为na_1；q的其他特殊值与零项按原题处理。
- 递推除因子、取对数、开方时检查取值和符号；分奇偶或周期规律须给依据，不能仅由数值猜测。
- 错位相减核对两端未抵消项和移动后的索引；裂项相消保留全部边界项；分组求和注意奇偶项数。
- 数学归纳法要检查起始值、归纳假设的指标范围和由k到k+1的步骤；不能在推导中使用尚未证明的k+1结论。
- 含参递推核对特殊参数导致的常数列、分母为零或推导失效。求最大项或最小正整数时必须处理整数取值和邻项比较。
