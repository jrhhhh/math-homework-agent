# 高中数学过程检查的判断尺度

| 类型 | 判断证据 | 常见修补 |
| --- | --- | --- |
| 运算错误 | 精确局部重算、代回 | 修正该步及连带结果 |
| 条件失效 | 定义域、非零、角范围、几何存在条件 | 补合法分类或改用有效变形 |
| 分支/边界遗漏 | 反例、首项、端点、另一组解或竖直直线 | 补讨论并回代 |
| 逻辑错误 | 必要充分混淆、举例代替全称、循环论证 | 明确推理方向和待证步骤 |
| 定理误用 | 定理所需条件与实际条件不符 | 使用适用的高中定理或直接证明 |
| 论证缺口 | 结论尚未由已有步骤支持 | 补理由；不能据此判命题必假 |

首错沿原步骤定位。对sqrt(x+2)=x，平方求候选根可合法，最后接受-1才可能是首错；若明确写成无条件等价，则错误已在该声明处。对含零因子的式子直接约分，可能导致漏解；后续错误移项仍是另一个独立错误。

正确但简略的推导、不同解法、等价形式不应判错。条件已由题设保证时不要求重复。答案碰巧正确仍需检查过程有效性。超纲方法的数学成立性与课程允许性分开评价；无评分依据不扣分。

反例须符合全部题设。仅有答案不能重建学生错误过程。图片模糊、几何条件缺失时指出具体缺口。工具计算、同一助手复核、独立验证、形式化证明分别表述。
