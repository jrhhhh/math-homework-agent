# 课堂模板选择与页面模板

## 选课型

| 模板 | 适用场景 | 必须填充的教学环节 | 源文件 |
|---|---|---|---|
| 新授课 | 引入概念、性质、定理或新方法 | 问题情境 → 旧知检索 → 探究 → 概括与边界 → 例题 → 练习 → 退出检测与归纳 | `assets/templates/concept-lesson.md` |
| 习题课 | 知识已学，发展策略与方法 | 入门检测 → 核心例题 → 策略选择 → 完整推导 → 变式辨析 → 独立迁移 → 方法归纳 | `assets/templates/problem-lesson.md` |
| 讲评课 | 提供了作答或诊断证据 | 匿名错例 → 判断依据 → 条件/分支审查 → 最小修订 → 同类再练 → 独立检测 | `assets/templates/review-lesson.md` |

没有实际学生证据时，用“合成错例”标注示例，不以预设错误概括班级薄弱点。模板是可以增删的教学框架，填入课题后需要重新求解、检查条件及调整课时。模板中的方括号是作者占位，成品交付前必须替换。

## 页面怎么用

以下结构可以改写成完整课堂，`[标题]` 等是渲染器支持的版式。`!note:` 写入 PPT 演讲者备注，`>` 是学生看到的主问；`!ans:` 只能一次性显示整块答案。复杂答案用后页讲解，尤其是未验证播放环境时。

### 问题情境页

屏幕：具体情境/数学对象与必要条件 + 一个有意义的任务。
备注：为什么此时提出、学生如何进入、预计用时、如何收集回答。
避免只有“观察与思考”标题，却没有可观察对象。

### 探究推进页

屏幕：已得到的式子/图 + 当前变化 + 一个待判断或待完成处。
备注：预期猜想、先问什么、不同回应如何处理、收束到什么结论。
连续探究页保留前一步关键结果，不能翻页后丢失条件。

### 概括与辨析页

屏幕：准确结论及条件 + 例或非例/适用边界。
备注：要求学生用自己的话说明含义，指出哪类错误被边界排除。
定义和定理不能省掉量词、条件或限制范围。

### 典型例题页组

题目页提出方法选择；下一页展示关键推导；再用检验或总结收束。
备注含完整解答与每步依据、策略选择理由、可以留给板书的部分。
不要把完整解答都放到一个过长的点击块，也不要只给最终答案。

### 独立练习页组

屏幕给完整题目、任务、作答方式和必要图形，答案放备注或后页。
备注给时间、答案、评分依据、常见风险及下一步反馈；练习不只是教学后的装饰。

### 退出检测与归纳页

短题独立检测本课目标；总结由“解决了什么、依据是什么、何时用、还需注意什么”构成。
教师根据实际结果决定后续，不预写“全班已掌握”。作业给题目或已核对的明确来源，不能捏造页码。

## 视觉母版与课堂模板

`assets/base.pptx` 保留 16:9 母版；上述 Markdown 文件定义教学页面结构，二者共同使用。可以替换用户底版，但切换母版不会自动产生提问、推导和练习。每个模板用真实数学内容填充，正文适合投影且颜色有明确含义；不靠空白页面或装饰图凑页。

可编辑 PowerPoint 模板与源码成对保存：`concept-lesson.pptx`、`problem-lesson.pptx`、`review-lesson.pptx` 均在 `assets/templates/` 中。模板中的占位符是备课填写区，不是可直接投放的课堂内容；填入具体数学材料后重新检查。

完整已填示例位于 `assets/examples/trigonometric/`：`lesson.md`、`lesson.pptx`、`figures.json` 和配图齐全，用于观察具体数学内容如何对应提问、练习与教师备注。该示例为合成习题课，不能作为真实教学效果证据。
