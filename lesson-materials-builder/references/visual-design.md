# 视觉模板与构图流程

教学内容模板回答“教什么、怎么引导”，视觉主题回答“整套怎样呈现”。二者都需要；空白底版或几页占位短句不能充当视觉模板。

## 1. 先确定整套视觉规范

大纲开头保留一段视觉设计决定：主题、主辅色、标题/正文层级、页面角色、图形表达及整套节奏；不在最终学生屏幕上展示这些制作说明。沿用用户已选择的风格，无指定时默认“绛红书院”。

| 主题 | 文件 | 视觉语言 |
|---|---|---|
| 绛红书院 | `assets/themes/scholar-red.pptx` 与 `.json` | 深绛红封面/结论、暖纸色内容、衬线标题、无衬线正文、红青区分并列分支 |
| 墨青研习 | `assets/themes/ink-teal.pptx` 与 `.json` | 深墨青封面/结论、浅灰绿内容、青色引导与暖棕对照 |

模板是原生 PowerPoint Layout，包含 Cover、Explore、Compare、Practice、Takeaway、Visual、Sequence、Notes 八类版式；版式背景可在“幻灯片母版”中编辑，课堂文字是幻灯片上的文本框。不是整页截图。

`assets/themes/showcase.md` 是模板样册源，`.preview.png` 是真实渲染预览；选择风格时先查看预览，再使用成对的模板与视觉规范。使用者也可直接打开样册 PPTX 修改。

## 2. 按页面任务决定构图

- 建立关注：封面用大面积主色、非对称分栏与大标题。
- 推导：对齐式子与依据，保持阅读轴；避免把每行公式装进独立卡片。
- 对照：左右并列，条件明确，留出等量的图文区域；并列关系不能画成先后箭头。
- 练习：题目区、书写区和主问分开，答案留备注或后页。
- 总结：用深色结论页收束，只强调经过前文建立的认识。
- 观察：图为主、标签可读，旁边或底部只留必要解释和问题。
- 流程：只有确实存在顺序关系才连线；`[流程]` 可用最多4个文字步骤，原生形状与文字可编辑；图片流程沿用原有语法。

整套交替出现观察、推导、作答、对照与收束；不要连续用同一空白标题列表。复杂数学内容跨页，但保留条件和关键前式。字号不随内容任意缩小，无法放下则拆页。

## 3. 实际应用

Markdown frontmatter 设置 `theme: scholar-red` 或 `theme: ink-teal`。`build_pptx.py --theme` 可明确指定；直接传入本项目生成的主题 PPTX 底版时，也会读取其内嵌主题标记应用相应版式；指定项目内置底版且无主题字段时，默认使用绛红书院。自备底版无主题字段时保留 classic 路径，避免静默覆盖用户母版。

已实现能力是这两个固定主题及八种页面角色；不声称具备 PPT Master 的任意 SVG 编译、品牌模板导入或所有原生图表能力。原生文字、形状与版式可编辑，数学 PNG 图内元素不可单独编辑。

## 4. 渲染后检查

输出整套缩略图观察节奏，再逐页放大检查正文、公式、图内标签、留白、对比度和关系表达。几何通过不能代替视觉审查。确认输出实际使用所选 Layout（不是只把主题名写在源码里），且教师备注、题目条件和答案没有丢失。发现拥挤或无意义留白时回到页内构图修正。

设计流程参考 [PPT Master](https://github.com/hugohe3/ppt-master) 的模板/风格/版式分工与先设计后生成原则；本主题与渲染代码独立编写，不复制其模板、代码或视觉素材，也不引入其运行时或授权流程。

维护模板时运行 `python scripts/build_theme_assets.py` 重新生成两套主题、三套课型模板和完整示例；加 `--render` 可输出主题预览，需要 LibreOffice、Poppler 和正确的中文字体。可用 `--fontconfig` 指定字体配置。
