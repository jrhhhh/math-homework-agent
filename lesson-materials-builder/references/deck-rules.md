# 教案 → 课件 转换规则

这些规则不是凭空定的，是从一份**配套样本**里比对出来的：用户「导数」一课的教案
（PDF，9 页）与同一节课的参赛 PPT（13 页）是同一节课的两种表达。把两者并排看，
能直接看出哪些信息从教案进了课件、哪些没进、以及进的形态发生了什么变化。

写大纲前先读这份文件。规则 2、规则 7、规则 9 是最容易被忽略、也最影响成品质量的三条
（分别是「怎么切页」「字号定死能写多少字」「怎么写才不像口水话」）。

---

## 规则 1：课件只搬「教学过程」，其余要素另置

教案里的教学目标、教学重难点、教学方法、教具准备，**不进教学页**。

理由：这些是写给教师和评委看的元信息，学生不需要在教学过程中看到。
把它们塞进教学页，会让原本应该聚焦于数学内容的页面变成行政文档。

去处：只在末尾的「阐述页」成页出现，且仅在比赛版追加。

| 教案要素 | 去向 |
|---|---|
| 课题、年级、教材版本 | 封面页正文行（**只在第 1 页**，内页不重复） |
| 教学目标 | 阐述页 |
| 教学重难点 | 阐述页；其内容本身影响教学页的**强调版式**选用 |
| 教学方法/理论依据 | 阐述页 |
| 教具准备 | 不进课件 |
| 教学过程 | **教学页正文** |
| 板书设计 | 小结页可复用其结构 |
| 作业 | 作业页 |

## 规则 2：按认知台阶切页，不按教案标题切页 ⭐

这是本技能的核心动作。

样本证据：教案的环节「（二）概念深入，从定性到定量层层推进」是一个 25~30 分钟的
大块，内部含 APOS 理论的**操作 → 过程 → 对象 → 图式**四个阶段。PPT 没有把它做成
一页，而是拆成了五页：

```
教案：环节(二) 25~30min
        └─▶ PPT: 定性看 → 定量看 → 极限 → 概念 → 意义
```

拆分的依据不是教案的小标题，而是**学生每翻一页要完成的思维动作变了**：

| 页 | 思维动作 |
|---|---|
| 定性看 | 感受：变化率在图上长什么样 |
| 定量看 | 计算：怎么把切线斜率算出来 |
| 极限 | 遇到障碍：无限算下去不行，需要新工具 |
| 概念 | 抽象：把工具命名为「导数」 |
| 意义 | 联系：几何意义、物理意义贯通 |

判据：**学生扫一眼这页，能不能说出「这页要我干什么」。** 说不出就是切错了 ——
多半是两三个思维动作被挤在一页，或者一页只承载了半句话。

反过来说，教案里的一个自然段如果对应同一个思维动作，就不该拆成两页。

## 规则 3：页面标题极短且对仗

样本标题：`温故知新` `两种速度` `定性看` `定量看` `实践探究` `课堂小结` `作业布置`

全部在 2~4 字。且「定性看 / 定量看」成对出现 —— 对仗本身就是给学生的一种结构暗示，
告诉他这两页是一组对照。

做法：标题控制在 12 字以内，同份课件内尽量保持相同的字数节奏。
标题不是句子，不要写成「通过函数图像理解瞬时变化率的几何意义」。

## 规则 4：每页以一句驱动性问题收尾

样本证据：

- P2「对于跳水，研究整体轨迹就足够了吗？我们如何研究一段时间内的变化？」
- P6「对于不同的点，不同类型的函数呢？能否用一个数学概念解决一般的问题？」

问题指向**下一页**，作用是让学生带着悬念翻页。这是课件区别于讲义的地方 ——
讲义可以把结论直接给出来，课件需要先制造需求再给答案。

做法：`课件.md` 里用 `>` 标记驱动问题，渲染为页内底部的强调行。

不是每页都要有问题。**每个认知台阶的最后一页**放一个就够了，页页都问反而麻木。

## 规则 5：配图密度分层

统计样本 13 页的图片数：

| 页 | 环节 | 图片数 |
|---|---|---|
| P2 温故知新 | 建构段 | 3 |
| P3 两种速度 | 建构段 | 0 |
| P4-P8 | 建构段 | 1,2,3,1,2 |
| P9-P13 | 总结/作业/阐述 | 0,0,0,0,0 |

规律很清楚：**概念建构段密集配图，总结段零图**。

理由：建构段要做的是「让抽象概念有图形依托」，图是主要的信息载体；
总结段要做的是「收束成结论」，此时文字才是载体，插图反而分散注意力。

P3 是个例外（建构段但零图）—— 那一页是纯概念对照（平均速度 vs 瞬时速度），
本来就没有几何对象可画。这说明规则是**倾向**不是铁律：无图可画时不硬凑，
但要能说清为什么。

## 规则 6：动态演示集中在建构段，答案晚于问题出现

样本实测（逐页读 `ppt/slides/slideN.xml`）：

| 页 | 环节 | 单击触发的进入效果数 |
|---|---|---|
| P1 封面 | — | 0 |
| P2 温故知新 | 建构段 | 4 |
| P3 两种速度 | 建构段 | 3 |
| P4 定性看 | 建构段 | 5 |
| P5 定量看 | 建构段 | 1 |
| P6 引入无穷小量与极限 | 建构段 | 1 |
| P7 导数的概念 | 建构段 | 0 |
| P8 导数的意义 | 建构段 | 4 |
| P9-P11 练习/小结/作业 | 结论段 | 0 |
| P12-P13 阐述 | 结论段 | 0 |

规律很清楚：**6 页带 `<p:timing>`，共 18 个单击效果，全部落在建构段；结论段零动画。**
这与规则 5 的配图密度分层是同一条道理的两种体现 —— 建构段是"一步一步搭起来"的过程，
所以需要分次呈现；结论段是"收束成结论"，一次给全反而有力。

P3 是这条规律最好的例子：那一页的**内容本身就是分次出现的** —— 平均速度 → 瞬时速度
→ 驱动问题，各一次点击。作者的做法是**让问题与知识点分次出现**，而不是一次性铺满。

> 早期版本这里写的是「结论段只有页面切换效果」。**这句是错的，已改。**
> 实测全文件里没有任何 `p:transition`（P12/P13 各有一个**空的** `<p:transition/>`，
> 空元素在 OOXML 里表示"无切换效果"）。当时读成了"有切换效果"，把"没有"读成了"有"。

**作者怎么处理"答案"**：他把问题分次放出来，答案则另起一页或直接上黑板 ——
配套教案的「板书设计」一节明确列着「例题 1 的解 / 例题 2 的解 / 例题 3 的解」。
所以那份参赛 PPT 里**一个例题页都没有**（`解：`、`证明` 零命中）。

本技能把"答案上黑板"换成两件事：`[例题]` 版式留出左下空白给手写，
以及 `!ans:` 让解答**点一下才出现**（见 SKILL.md「先问题后答案」一节）。
这是新增设计面，不是照搬样本 —— 但方向与作者一致：**不要让答案早于讨论出现。**

做法见 SKILL.md 的「动态演示的能力边界」一节。优先流程页，其次 GIF，然后是 `!ans:`。

**流程页与 GIF 的分工**：流程页是把 N 个静态瞬间排在同一页上，靠箭头表达顺序 ——
学生能同时看到「上一步长什么样」，适合分割、拼接、逐步逼近这类过程。GIF 是真正的
连续动画，适合「动起来才能看懂」的事（如割线随 Δx 收敛为切线）。两者可叠加：
流程页里放一张 GIF 也是合法的。

**什么时候该用 `!ans:` 而不是流程页**：流程页回答的是"这个过程分几步"，`!ans:` 回答的是
"这个问题的答案是什么"。教案里写着「提问：……引导学生得出结论」的地方，用 `!ans:`；
写着「演示分割过程」的地方，用流程页。前者要的是悬念，后者要的是对照。

早期版本有个「分步页」版式，把同一过程拆成 N 张幻灯片。已废弃 ——
翻页会丢掉上一步，而恰恰是这个「上一步」在支撑推理。`[分步]` 仍能渲染，
但会被改名成 `[流程]` 并提示。

## 规则 7：字号本身就是「简洁性」的执行手段 ⭐

样本实测的字号体系：

| 用途 | 字号 |
|---|---|
| 封面主标题 | 70pt（10 字以上 54pt，14 字以上 44pt） |
| 页面标题 | 32pt 粗体 |
| 正文标准 | **28pt**（内容稀疏时自动升到 30pt） |
| 二级要点 | 24pt（一级的 0.857 倍） |
| 强调结论 | 32pt |
| 驱动问题 | 24pt |
| 流程页说明 | 20pt |
| 阐述页细则 | 16pt（固定） |

28pt 看起来是个随意选的数，其实是**物理约束**：13.33 英寸宽的页面上，
28pt 的中文字一行放不下 20 个字，一页放不下 8 行。字号一定，能写的字数上限
就定了，人被迫删字 —— 这就是「简洁」是怎么被强制执行出来的。

所以**不要为了多塞内容而调小字号**。正确做法是拆页（回到规则 2）。
`build_pptx.py` 只会把正文放大到 30pt，永远不会低于 28pt（阐述页细则 16pt 是唯一
的小字号例外，那是给评委看的细则，不是给学生看的正文）。装不下时脚本会告警并
报出它实际用了多大的字号 —— 看到告警就去拆页，不要去改字号。

**字号不是消解留白的唯一手段。** 一页只有三行要点时，把字放大到 30pt 仍会空掉
大半页；正确反应是**拉开间距**：段后距从 10pt 加到 26pt、行距从 1.30 倍加到 1.60 倍，
再让整个文字块在正文区里**垂直居中**。渲染器按这个顺序自动做（字号 → 段后距 →
行距 → 居中），因为间距是可逆的微调，字号是不可逆的承诺。三档都到顶仍有大片空白
就停手 —— 宁可留白，也不要把版面撑变形。此时若占用率仍低于 35% 会告警建议补内容。

## 规则 8：加粗只给两类内容

样本里加粗的项：`瞬时`（术语）、`定性看`（小标题）、`几何意义` `物理意义`
`抽象概念`（术语）、`数形结合，以直代曲`（结论句）。

只有两类：**核心术语** 和 **结论句**。

理由：加粗是稀缺资源。如果一页上有一半的字是粗的，等于没有重点 ——
学生的眼睛失去了落点。把加粗留给「这页必须记住的那个词」和「这页要得出的那句话」。

反例：把「我们」「因此」「可以看到」这类过渡词加粗，纯属噪声。

## 规则 9：要点行是书面短语，不是聊天 ⭐

这是最容易漏的一条 —— 规则 1~8 管的是「写多少」（标题 ≤12 字、一级要点 ≤6 行、
加粗只给术语与结论），**没有一条管「怎么写」**。于是下面这些句子曾零告警地通过构建：

| 原句 | 毛病 | 改成 |
|---|---|---|
| 长 × 宽 × 高，体积谁都会算 | 口语评价 | 体积公式：V = Sh |
| 斜着推一下，成了斜棱柱 | 口语动量词 | 推成斜棱柱，各层截面不变 |
| 把它斜着推一下，变成一个斜棱柱 | 悬空代词 + 口语动量词 | 推成斜棱柱，各层截面不变 |
| 1500 多年前，祖暅总结出它 | 悬空代词「它」 | 祖暅于 1500 多年前提出 |
| 锥体是它的 1/3 | 悬空代词 | 锥体体积为等底等高圆柱的 1/3 |
| 怎样用它算出体积？ | 悬空代词 | 如何据此求体积？ |
| 要求只用以前学过的知识 | 口语叙述 | 限用已学知识 |
| 一叠整齐的书，形状是长方体，体积是 V = Sh | 三件事挤在一条 | 一叠书 → 形状：长方体 → 体积 V = Sh |
| 书没有增减，只是错位 ——<br>每一层截得的面积始终相等 | 一句话断在破折号上，拆成两条 | 各层截面不变，仅位置错开 |

四条判据：

1. **不写主语。** 去掉「我们 / 你 / 大家」—— 要点行的主语是数学对象本身，
   不是讲课的人。`我们可以用二次函数拟合跳水的轨迹` → `用二次函数拟合跳水轨迹`。
2. **不用代词回指。** 「它 / 这样算 / 此」一律换成术语复现。幻灯片是**跳着看**的，
   学生可能从任何一页开始看，代词没有可回指的上下文。
3. **禁口语词。** 一下、谁都会算、还行吗、凭什么、变多、只剩、原来、其实。
   （`还行吗`/`凭什么` 出现在**驱动问题**里是合法的 —— 那是问句，见下面自测法。）
4. **一句一个信息。** 不写用逗号或破折号串起来的散文句，拆成两条短语。
   一个逗号的「若…则…」条件句不算违反，两个逗号串三件事才是。

**自测法：把要点行念出来。像在跟学生聊天，就是口水话。**

念出来这个动作本身有诊断力，因为口语和书面语的差别主要在**节奏**而不在用词：
「斜着推一下，成了斜棱柱」念着顺口、像在讲解；「推成斜棱柱，各层截面不变」念着
有点紧、像在板书。要的就是后者 —— 幻灯片上的字是**提词**，讲解的口气由老师的声音
提供，不该写进字里。字和话都口语化，等于说了两遍。

`build_pptx.py` 的 `check_wording` 按这张表自动扫一遍（词典命中的高置信、
断句启发式的低置信），但机器只能抓词和标点 —— **判据 1 和判据 4 的实质要靠念。**

## 版式选用表

`课件.md` 里用 `# [版式] 标题` 指定。选用依据：

| 版式 | 用在 | 结构 |
|---|---|---|
| `封面` | 第 1 页 | 课题 + 讲师 + 教材版本 |
| `标题` | 单栏内容页 | 标题 + 要点列表（≤6 行）+ 可选配图/驱动问题 |
| `两栏` | 对照、图文并置 | `## 左` / `## 右` 两栏，适合「图 + 说明」或「A vs B」 |
| `重点` | 核心术语的定义、必须记住的结论 | 大字号居中，`!!!` 行渲染为强调块 |
| `纯图` | 全幅图形 | 标题 + 一张占满版面的图 |
| `流程` | 需要看清「上一步长什么样」的连续过程 | N 张图横向并排 + 箭头，每图下方一行说明，建议 ≤4 步 |
| `例题` | 要留出解答/板书空间 | 题干贴顶占满版心；配图挂在题干下方**偏右 40%**，**左下 60% 留白**给解答或手写；`!ans:` 落在留白里 |
| `阐述` | 比赛版末尾 | 教学目标 / 重难点及解决，仅比赛版追加 |

`[例题]` 的留白是**故意空着**的，别拿它当"排版没排满"去补内容 —— 那块地方要么放
点击后显现的解答，要么就是留给老师在投影上写、或学生上台写的。作者本人的参赛 PPT
里一个例题页都没有（他把例题的解全留在黑板上，见规则 6），所以这个版式是本技能
新增的设计面，样本验证不了它。

配图是**可选**的（用户说的是"如果有配图"）：没有配图时下半区整片留白，解答块放宽到
满版心。题干**固定 28pt 不参与自适应填充** —— 填充的职责是把文字撑满可用高度，
与"故意留白"方向正好相反。题干太长要改的是题干本身，不是让它去占满下半页。

`[标题]` 版式内部的图文关系**由图自己决定**，不用手写版式：图的宽高比 < 1.5
（竖幅、方形）走左文右图并排，≥ 1.5（横幅）走上图下文占满版心。两种情况下图都在
自己那一栏/版心内水平居中，文字块在正文区垂直居中 —— 竖幅图不必自己裁成横幅来迁就版面。

`[分步]` 是旧版式名（同一过程拆成 N 张幻灯片），仍可用但会被改名成 `[流程]`。

## 强调与结构标记

| 标记 | 渲染为 | 用在哪 |
|---|---|---|
| `- 文本` | 要点行，28pt | 正文 |
| `  - 文本` | 二级要点，24pt | 从属说明 |
| `**文本**` | 加粗 | 仅核心术语与结论句（规则 8） |
| `!!! 文本` | 32pt 居中强调块 | 本页要得出的那句话 |
| `> 文本` | 页面底部的高亮问题行 | 驱动问题（规则 4） |
| `!img: 路径 [h=4.5]` | 插图 | 建构段（规则 5） |
| `1. !img: 路径 \| 说明` | 流程页的一步 | `[流程]` 版式内（规则 6） |
| `!ans: 文本` | 解答块，**放映时点击一次整块出现** | 教案写着「引导学生思考讨论」处（规则 6） |

供理解规则 2 的实际粒度。左列是教案，右列是 PPT。

课题/教材版本                        →    P1  封面

（二）概念深入 25~30min
      1. 定性：切线斜率               →    P4  定性看          [1图+动画]
      2. 定量：APOS 操作阶段          →    P5  定量看          [2图]
         过程阶段（引入极限）         →    P6  引入无穷小量与极限[3图]
         对象阶段（导数定义）         →    P7  导数的概念      [1图]
         图式阶段（几何/物理意义）    →    P8  导数的意义      [2图]
