# [标题] 先因式分解
<!-- 允许无图 -->
- sin(2x)=sin x，0≤x<2π。
- 二倍角展开：2sin x cos x−sin x=0。
- 提取公因式：sin x(2cos x−1)=0。
> 接下来要保留哪些分支？
!note: 推导页：沿着同一阅读轴组织式子；追问零因子性质，而非直接公布全部结果。

# [例题] 独立练习
- 在 0≤x<2π 内解 sin(2x)=−sin x。
- 写出分支、解集及每一步的依据。
> 哪一支保留，哪一支改变？
!note: 练习页：上方题目区，下方书写区；答案不提前上屏。解集{0,2π/3,π,4π/3}。

# [重点] 完整性的依据
- 变形等价，未删去任何可能的解。
- 分支穷尽，各支在区间内列全。
- 合并解集，检查端点与结果。
!!! 解成立与无漏解，需要分别说明。
!note: 结论页：深色背景和大字形成节奏转换，只承载需要带走的核心认识。
