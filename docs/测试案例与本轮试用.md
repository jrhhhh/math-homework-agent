# 测试案例与本轮试用

日期：2026-10-08。以下为本次创建会话中，同一助手依据技能规则给出的试用回答及自查。测试设计、回答、评价由同一助手完成，不属于独立盲测，也不是另外启动的模型调用记录。为方便比较，除提示用例外均要求“只检查，不出变式题”。

## T01 增根及首错位置

输入：解 sqrt(x+2)=x。学生：“平方得 x+2=x²；解得 x=2 或 -1；所以原方程的解为 2、-1。”

验收：首个明确错误在最后接受两个候选解；不能直接判“平方错误”。

本轮回答：计算候选根的过程成立，错误在最后把 -1 也列为原方程的解。左边非负，故 x≥0；-1 代回得到 1=-1，不成立。2 代回成立，原方程解集为 {2}。

自查：符合。

## T02 消去零因子导致漏解

输入：解 x(x-1)=0。学生：“两边除以 x，得 x-1=0，所以 x=1。”

验收：定位到未经讨论就除以 x，指出 x=0 分支。

本轮回答：第一处错误是直接两边除以 x，原题允许 x=0。由乘积为零可得 x=0 或 x-1=0，所以解集为 {0,1}。最后漏解是这次不合法消去的后果。

自查：符合。

## T03 不等式方向

输入：解 -2x>6。学生：“两边除以 -2，得 x>-3。”

验收：定位除负数时未反向，严格边界不包含 -3。

本轮回答：错误在除以负数后保持了原不等号方向。两边除以 -2 应得 x<-3，解集为 (-∞,-3)。x=-3 时两边相等，不满足原来的严格不等式。

自查：符合。

## T04 定义域端点

输入：求 f(x)=sqrt(x-1)/(x-2) 的定义域。学生：“根号内非负，所以 x≥1，定义域 [1,+∞)。”

验收：补分母非零条件，保留 x=1，排除 x=2。

本轮回答：x≥1 这一步正确，但最后的定义域遗漏分母不能为零的条件。还须 x≠2，因此定义域为 [1,2)∪(2,+∞)。

自查：符合。

## T05 正确的不同解法

输入：解 x²-6x+5=0。学生：“(x-3)²=4，所以 x=1 或 5。”参考解法用求根公式。

验收：接受配方法与合理省略，不强行纠错。

本轮回答：解答正确。配方保持等价，由 x-3=±2 得到 x=1 或 5，两个值都满足原方程。你的配方法可以直接使用。

自查：符合。

## T06 只有答案

输入：解 x(x-1)=0，我只写了 x=1。帮我诊断。

验收：指出漏解，但不推断学生一定除以了 x。

本轮回答：答案不完整，x=0 也满足原方程，完整解集为 {0,1}。未提供过程，无法定位具体出错步骤。

自查：符合。

## T08 参数为零

输入：a 为实数，解 ax=1。学生：“除以 a，得 x=1/a。”

验收：分 a=0 与 a≠0 两类，不直接补设 a≠0。

本轮回答：第一处问题是未判断 a 是否为零就除以 a。a≠0 时 x=1/a；a=0 时原方程为 0=1，无解。

自查：符合。

## T09 错误参考答案

输入：解 2x+1=5，我得到 x=2，但参考答案 x=3。请检查。

验收：以原题为准，不能附和参考答案。

本轮回答：你的答案 x=2 正确，代回得 2×2+1=5。参考答案 x=3 代回左边为 7，不满足原题。

自查：符合。

## T10 提示模式连续两轮

输入：解 sqrt(x+2)=x。我平方后得到 x=2 或 -1，都写进答案了。只提示，不告诉答案。

验收：一次一个提示，不揭示应保留的根；“还是不懂”之后仍不直接公布答案。

本轮第一答：原方程左边一定非负，这对右边的 x 有什么要求？

学生追问：还是不懂。

本轮第二答：把你得到的两个候选值分别代回原方程，检查左右两边是否相等。

自查：符合；这是本文件内的模拟互动，尚未进行跨消息自动化回放。

## T11 首错与独立错误

输入：解 (x-1)(x-2)=0。学生：“除以 x-1 得 x-2=0，因此 x=-2。”

验收：识别未分情况消去与独立移项错误，不把二者都归为同一错误。

本轮回答：第一处错误是直接除以 x-1，这会漏掉 x=1。后面从 x-2=0 得到 x=-2 是另一处独立运算错误，应为 x=2。因此原方程的解集为 {1,2}。

自查：符合。

## T12 答案碰巧正确

输入：解 2(x-1)=4。学生：“展开得 2x-1=4；移项得 2x=6；所以 x=3。”

验收：最终答案正确不能掩盖两处错误。

本轮回答：x=3 是正确答案，但过程有两处错误。首错是展开：2(x-1) 应为 2x-2。另一步由 2x-1=4 移项应得 2x=5，也不是 6。正确过程为 2x-2=4，2x=6，x=3；代回原方程成立。

自查：符合。
