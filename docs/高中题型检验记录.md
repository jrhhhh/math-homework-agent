## 本轮案例复核

以下为当前助手按修改后的规则完成的案例诊断与同一助手复核，不是独立盲测或自动模型评测。除提示案例外均要求“检查过程，给最小修改，不出新练习”。

| 编号 | 测试输入：原题与学生步骤 | 本轮诊断与最小修改 |
| --- | --- | --- |
| H01 三角解集 | 0≤x<2π，sin x=1/2；学生仅写x=π/6并断言只有一个解 | 已写解正确，首错在“只有一个”。补x=5π/6，两个解均在区间内。 |
| H02 三角除零 | 0≤x<2π，sin 2x=sin x；学生用二倍角后除以sin x，得cos x=1/2，仅写π/3、5π/3 | 首错是未讨论sin x=0就相除。因式分解为sin x(2cos x-1)=0，补0、π；四个解为0、π/3、π、5π/3，2π不包含。 |
| H03 椭圆焦距 | x²/9+y²/4=1；学生a=3,b=2,c²=a²+b²=13 | 首错在焦距关系，应为c²=9-4=5。若求离心率则e=√5/3。 |
| H04 抛物线约定 | y²=4x；学生套y²=2px，p=2，写焦点(2,0) | 参数识别正确，焦点换算错误；在该约定下焦点(p/2,0)=(1,0)。 |
| H05 联立退化 | 双曲线x²-y²=1与y=x+1联立；学生说“必为二次方程，因此有两个交点” | 首错是未经检查断言二次。代入得-2x-1=1，是一次方程，唯一交点(-1,0)。不使用二次判别式。 |
| H06 导数与极值 | f(x)=x³；学生f'(0)=0，所以0是极小值点 | 导数计算正确，推论错误。函数在0左右均递增，也可用左右函数值异号说明0不是极值点。 |
| H07 不可达下界 | x>2，求x+1/x最小值；学生由基本不等式得≥2，所以最小值为2 | 下界不等式正确，错误是声称2取到。等号需x=1，不在范围。f'=1-1/x²>0，且f(x)-5/2=(2x-1)(x-2)/(2x)>0，x趋近2右侧时趋于5/2；无最小值，下确界5/2。解释为“可无限接近但取不到的下界”。 |
| H08 首项 | S_n=n²+1，n≥1；学生差分得a_n=2n-1，称对所有n≥1成立 | 首错是把仅适用n≥2的差分结论推广到n=1。补a_1=S_1=2，n≥2保持原公式。 |
| H09 特殊公比 | a_1=2、q=1；学生用2(1-q^n)/(1-q)，认为0/0所以和不存在 | 首错是使用要求q≠1的公式。数列每项为2，S_n=2n。 |
| H10 线面垂直条件 | 平面α中有直线a，l⊥a；学生直接断言l⊥α | 该条件不足。可取α为xy平面、a为x轴、l为y轴，满足l⊥a但l在平面内。需额外证明l垂直平面内另一条与a相交的直线，不能擅自补题设。 |
| H11 互斥与独立 | 掷公平骰子，A为奇数、B为偶数；学生说互斥所以独立 | 首错是把互斥当作独立。P(A∩B)=0，而P(A)P(B)=1/4，因此不独立。 |
| H12 正确数列 | a_1=3，a_(n+1)=a_n+2；学生得a_n=2n+1、S_n=n(n+2) | 过程成立：通项满足首项和递推，等差求和得到n(3+2n+1)/2=n(n+2)。不因省略机械计算判错。 |
| H13 提示模式 | 对H08的解答，用户说“只给一个提示，不告诉答案” | 输出：“你使用S_n-S_(n-1)时，n=1会涉及哪一个前缀和？原题给出的公式是否覆盖这个下标？”不公布首项或通项。 |
