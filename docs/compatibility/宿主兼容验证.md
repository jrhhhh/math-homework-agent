## 工作台真实后端实测

2026-11-03，使用 DeepSeek Harness CLI 0.2.1-rc.5 和 DeepSeek API，在隔离临时目录运行；设置页面“测试连接”成功。在独立测试数据库中，页面提交三角方程 `sin(2x)=sin(x)`，学生错误地两边除以 `sin(x)`；工作台调用真实模型并通过诊断结构检查，指出除数为零的分支，给出漏掉的 `0` 和 `π`，最终解集正确。此测试只覆盖连接与一次过程诊断；并未验证该后端上的全部教学流程和课件生成。

隔离模型模拟测试在发送给本地替身的模型请求中检查到可用工具列表为空；该模拟只验证接线和权限配置。桌面会话的第二轮真实调用读取学习证据、补救教学和课件技能及其模板，输出模拟证据、10 分钟一对一补救草案和待确认的 7 页大纲；没有真实任务绑定、未生成 PPT。人工核对发现总结页没有反复标明 `a>0` 条件，以及一条提示过早给出关键值，因此更新了课件技能的条件和提示检查要求；尚未在相同场景重新验证该技能修改的效果。
