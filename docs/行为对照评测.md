# 2026-10-10 诊断 Skill 行为对照评测

## 设计与真实执行

使用同一组12个高中短文字案例，比较普通数学问答与加载 Math Error Diagnosis Skill 两种条件。题型包括三角、椭圆、数列、函数、代数、双曲线和概率；同时覆盖正确解答、只有答案、错误证明、单提示、缺少原题及学生文本内的干扰指令。

两个作答子代理均以 `fork_turns=none` 启动，每个条件一次，未提供参考答案、验收要点或另一组输出。Skill条件允许读取入口和必要参考；基线只读取测试输入，不加载技能。两组都继承当前宿主模型与推理设置；无法核实精确模型版本，不能据此声称可逐字复现。

第三个新上下文核验者只收到原题和匿名A/B回答，自行推导再评分，没有读取Skill、条件映射或先前结论。A/B位置逐题交替，非随机。原始回答保持原样，不为展示修改回答。

## 评分与结果

四项二值标准：数学正确性、首错定位/不强造错、反馈模式遵守、依据与边界。单题四项全通过才记为整体通过；不按文字长短评分。

| 指标 | 普通问答 | 使用 Skill |
| --- | --- | --- |
| 数学正确性 | 12/12 | 12/12 |
| 首错定位/不强造错 | 12/12 | 12/12 |
| 反馈模式 | 12/12 | 12/12 |
| 有据且不编造 | 12/12 | 12/12 |
| 整体通过 | 12/12 | 12/12 |

本轮没有观察到评分失败，也没有证明 Skill 比普通问答提高正确率。短题上基线也已充分，出现满分的天花板效应。不能把本表写成总体准确率100%或Skill增益已得到证明。

可见的反馈差异：E06的Skill回答明确说明无法定位未提供的步骤；E10的Skill回答区分错误方程下局部计算成立与另算过程尚未提供。基线未编造这些信息，同样通过评分；以上是表达完整度观察，不额外算作效果提升。

## 本轮改进及后续检验

- 诊断description明确排除大学数学专项、没有学生过程的从零求解和仅优化成立解法；仅核对答案按明确要求处理。
- 优化技能删除“未展示即不会”的学段措辞，将脚本裁决限定为结构与措辞，数学及教学质量另审。
- 原有同一助手试用记录之外，补充真实不同上下文作答、独立匿名核验与可重算汇总。未虚构失败案例。

下一轮应加入较难的高考多问综合题、有效但非常规解法、参数临界值及真实连续追问；每条件多次运行并由教师/同学按隐藏验收点复核。应增加域外任务的实际路由测试，不能把description编辑当成自动路由已通过。

## 原始材料与复现

材料位于 [tests/behavior-evaluation/2026-10-10](../tests/behavior-evaluation/2026-10-10/)：

- `inputs.json`：原始用户请求。
- `baseline.json`、`skill.json`：两组真实回答。
- `blind.json`、`mapping.json`：核验者实际看到的匿名包及事后条件映射。
- `review.json`：独立推导、逐题评分和具体理由。
- `protocol.json`：上下文隔离、条件、指标和限制。
- `summary.json`：由下述标准库脚本生成的汇总。

```bash
python3 tests/behavior-evaluation/summarize.py
```

此命令只核对并汇总已保存评分，不调用模型、不重新评价回答。重新开展行为评测时，将输入分别提供给普通问答与Skill两个新会话，隐藏评分/已有回答；随后将回答匿名交给新的核验者。模型输出可能变化。

本轮是同一模型、不同上下文的独立复核，不是人类、异模型或形式化验证；每位作答者在同一上下文中依次作答12题。没有测试OCR、自动技能选择、真实跨消息提示保持或优化建议质量；也没有构建线上自动Verifier服务。结果只适用于保存的这批回答。
