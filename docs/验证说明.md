# 验证说明

本项目包含三个技能、根目录调度规则、交接协议与标准库检查脚本。历史试用和审查记录已合并为本说明及 [代表案例](代表案例.md)。

## 复现方法

在仓库根目录使用 Python 3，无需安装第三方运行依赖：

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 tests/核验测试数学.py
python3 tests/新例计算核验.py
python3 tests/高中题型计算核验.py
```

- 衔接回归测试：8项，覆盖准入状态、当前内容版本、非法协议、退出码、卡片接口、额外字段及非UTF-8输入。保留数学错误卡片通过两门的反例。
- draft-coach 门测试：`draft-coach/tests/` 下共38项（`test_validation.py`：结构门 + hint；`test_audit.py`：审计门 + refuse；`test_partition.py`：分区门），覆盖六维结构（缺维度、评分越界、任一分维的「不适用」及原因提醒、习惯 1–3 条、重复习惯、多余字段、`positive` 只许出现在划改维度）、四类非法输入、越界反例（贴标签 / 题量计划）、假设性风险与版面词汇的放行、学段用词错配、整张草稿纸多题提示（含 `f(1)=-2` 不误报），以及 `refuse` 三个出口的退出码与可复现性。
- 草稿门层报告测试：`tests/test_draft_gate_report.py`，7项，覆盖报告本身的退出码与字段——干净卡过两道门、结构损坏卡退出1、仓库自带反例卡因越界措辞被审计拦住、多题草稿按块过门（`audit_draft` 覆盖整份 `draft`，否则整张纸会误触发 `W_MULTI_PROBLEM_DRAFT`）、未产卡片记 `none` 并核对回答里出现了哪条标准话术、skill.json 缺失 / id 错位 / 有卡片却拿不到草稿三类走退出码2，以及已保存材料的 id 对齐自洽。
- 固定数学计算：分别10、6、11组，共27组。后两个脚本生成相邻JSON证据，首个输出JSON到终端；结果可重建，不提交生成文件。

- 新增12题普通问答与Skill对照、匿名独立上下文复核，完整方法、原始回答和限制见 [行为对照评测](行为对照评测.md)。

## 审查要点

PR #1 合并前已修复非法编码输入的JSON错误输出、基本不等式非负条件、固定三方向诱导凑数、单题能力标签四项问题。优化方向不足三个真实改进时不生成卡片，说明原因；不虚构短板。

## 验证边界

交接脚本只核验元信息、当前题目与过程版本，不证明数学正确性、身份或授权。卡片validate/audit只检查结构与措辞；宿主需审查建议的数学依据和实际改进。

draft-coach **只看版面习惯，不判断计算对错**。结构门只查卡片结构；措辞门只查越界措辞。它**不核实版面观察是否属实**（例如卡片说某处"挤在一行"是否真的如此），也不判断数学。**没有人工复核的草稿习惯卡不构成对学生的结论。**

图片与 OCR 依赖宿主，**本项目不含手写转写技能**：图片草稿的内容只能由学生自己给出文字，本项目只处理文字还原或学生给的文字描述。

较早代表案例由同一助手产生与复核；本次新增评测采用不同作答上下文和匿名独立复核，仍使用同一模型，不是人类或异模型验证。浮点样本不能证明解集完备；一般结论仍须分类、边界与代数推导。未验证自动技能选择、真实跨消息提示保持或图像识别，不能据有限案例声明任意高考题可靠性。

草稿门层报告（`tests/behavior-evaluation/draft_gate_report.py`）只重放已保存卡片的退出码，**不重新调用模型、也不重新作答**；它读出的"全部通过"只说明卡片没越过结构线与措辞线，不说明版面观察是否属实。2026-10-15 的12条合成草稿评测针对的是旧版“查错”技能，结果只作历史参考，不能用来评价当前版面习惯技能。
