# 五分钟演示脚本

1. 启动：`python3 run.py`，打开 http://127.0.0.1:8765 。介绍官网红配色、三条任务入口和练习历史。
2. 单提示：载入示例，保持“只给一个提示”，提交除以 sin(x) 的丢解过程。观察真实反馈只提示检查 sin(x)=0。
3. 学生修订：将过程改为

   ```text
   用二倍角公式得 sin(x)(2cos(x)-1)=0。
   分别得到 sin(x)=0 或 cos(x)=1/2。
   所以在给定范围内，解为 0、π、π/3、5π/3。
   ```

   显式切换“检查我的过程”，提交。观察重新核验与版本增加，旧结果标记为历史失效。
4. 从零求解：新建练习，只输入“解实数方程 √(3x+4)=x”，选择“完整求解”，查看答案、可检查步骤与结构门记录。说明模型自查和外部工具检查的区别。
5. 草稿版面：新建练习，选择“看看草稿习惯”，输入两栏、末尾挤行、底部无留白的描述；不需要原题。查看观察是否对应实际描述，不把它当作数学批改。
6. 展示证据：展开运行记录，查看真实门退出码；查看修订历史，导出练习 JSON。打开三组真实实验报告，明确讲出是否观察到增益与证据限制。

可选演示：选“优化已核验的解法”，先提交一道正确且完整的学生过程，观察先出现诊断阶段，再出现三个优化方向；改成错误过程后重提，应停留在诊断反馈、不生成优化卡。

演示必须显示真实调用结果。网络或登录失败时如实说明；不要用预写答案伪装现场模型调用。可使用已保存的真实练习历史作为离线复盘，需明确标为历史。
