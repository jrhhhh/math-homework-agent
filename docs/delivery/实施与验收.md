四技能串联的真实本地调用证据见 `docs/delivery/evidence/four-skill-refine.json`：同一份学生原文先经过诊断契约，再由版本交接脚本放行，正解优化卡经结构与严格措辞两道门后展示。首次优化输出未通过 JSON 外层契约，随后一次有限修正通过；原始失败没有从证据里删除。界面说明由宿主按已验收卡片生成，避免技能自由文本声称未经执行的脚本结果。

第五个 Skill 的完整源码、回归夹具和评估材料位于 `lesson-materials-builder/`。统一调度将其接入课前备课与课后补救路径，要求先确认教学参数和课件大纲；数学推导仍由 Math Solver 或教师另行复核，PPT 结构/几何检查不冒充数学审稿。`scripts/verify_all.py` 已纳入该 Skill 的 36 条确定性回归断言。当前回归使用两个专用测试标记完成隐私探针；发布前还需用实际分享对象的姓名/学号执行该技能的隐私扫描。

## 本轮新增：师生任务链

新增 learning-task-designer、learning-evidence-bridge、remedial-lesson-planner 三个 Skill，现共八个子技能。工作台支持教师发布固定原题、学生领取并作答、教师读取当前诊断、起草可编辑补救教案并转入备课、布置关联再练习。学生修订后旧计划过期；备课的大纲/源码/渲染入口也检查来源版本。

当前是本机单设备协作演示，不含班级账号或跨设备权限。全量验收为 209 个单元测试及原有 Builder/Schema/数学固定核验，全部通过；新 Skill 结构检查通过。浏览器的完整链路、过期状态及桌面/移动视口使用明确测试替身验证；任务草案与补救规划还各做一次真实模型接口冒烟。二者都不能证明新技能带来教学效果提升，也不改变此前真人复核未完成的状态。详细接口与复现命令见 `docs/teaching-loop.md`。


## 2026-10-27：学习路径与可靠运行验收

目标、成功标准、固定原题、教师提示与活动模板统一保存在任务项中。学生可在尝试、按需帮助、数学操作和关联新题复核之间返回；提交保存不可变帮助快照，受助修订与未记录帮助的新题表现分开。任务中心保存长任务、阶段回执和事件；中断后手动继续，文件哈希失效时重建。详细约束、兼容接口、OpenMAIC 参考来源和恢复限制见 [学习路径与任务恢复](../learning-path.md)。

本轮实际执行：合并 main 的模型设置、附件、归档功能后，全量 **266 个单元测试通过**，含 106 个工作台测试；Builder 36 条回归、Schema 与固定数学案例检查通过。测试包括独立子进程崩溃后的人工继续、阶段复用、停止边界、请求去重、容量、课件真实脚本流水线与产物篡改后重建、帮助历史不可变、原题会话重绑、兄弟复核题去重。隐私探针采用两个专用测试标记，只验证扫描机制，不代表实际身份信息已审核。

浏览器运行师生闭环、学习路径与数学活动三组脚本：桌面 1280px、移动 390px 无横向溢出，无页面脚本异常。实际测量单位圆 SVG 宽高一致，零步长显示导数切线而非 0/0。记录及截图见 [浏览器验收摘要](evidence/browser-learning-path.json)。浏览器诊断和任务生成使用隔离的显式测试替身；组件计算、课件 Builder 和独立子进程恢复测试实际执行，不用替身结果冒充模型能力。

真实模型接口冒烟覆盖任务草案、补救教案和关联独立复核草案，记录见 [模型接口记录](evidence/teaching-loop-model-smoke.json)。学生诊断仍为已注明的合成输入，这不是数学准确率或教学效果实验。先前冻结评测与真人复核状态保持原边界。

集成同时验证练习删除：有排队/运行诊断时拒绝删除；任务结束后删除会清理帮助快照和相应诊断任务记录，避免悬空恢复或遗留帮助文本。已被教学任务引用的练习仍按原约定禁止删除。测试中的 CLI 缺失分支使用显式替身，不依赖开发机是否安装 Codex。
