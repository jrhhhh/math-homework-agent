# 界面设计与配色来源

2026-10-22 直接读取华东师范大学官网首页及两份外链样式表：

- https://www.ecnu.edu.cn/
- https://www.ecnu.edu.cn/css/style.css
- https://www.ecnu.edu.cn/css/index.css?v=2021081601

两份样式表中均使用 `#b70031`、`#a31f34`；首页样式还使用 `#850023`、`#f3f2ef`、`#333`。

工作台采用官网主红 `#b70031`、交互深红 `#850023`、米白 `#f3f2ef`、正文 `#333`，浅红反馈区为配套衍生色。参考配色，不复用学校校徽，也不表示校方背书。

信息布局：练习历史侧栏、输入与反馈双栏、下方不可变版本记录。窄屏改为单栏。正文采用苹方/微软雅黑，标题采用本机宋体类字体；无外部字体或前端运行依赖。动态内容一律使用 textContent，避免学生文本变成可执行 HTML。

用户审阅后移除自行命名的“数习”和圆形 Σ 徽章；使用项目原意“数学作业智能体”，配简洁书页线条标识。
