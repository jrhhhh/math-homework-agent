# 高中数学教师 Agent：完整教学流程实测

**测试对象**：`math-homework-agent`，源码提交 `b5265efea88b7933bcd332d5e1bf6c5db1a1e9cd`。  
**执行日期**：2026-10-27。  
**方式**：在 `127.0.0.1:8768` 使用独立 SQLite 数据库，通过真实浏览器操作工作台，使用已登录的 Codex CLI 和用户默认模型；所有题目、教师材料、学生文字与外部帮助均为测试人员构造。工作台的真实模型、教学流程和课件 Builder 均被调用，本次不使用模型替身。

## 测试材料与独立数学核对

- 原题：在 `0≤x<2π` 内解 `sin(2x)=sin x`。标准解为 `{0, π/3, π, 5π/3}`。
- 首次学生过程：直接除以 `sin x` 后只写出 `π/3、5π/3`，预期首错为未讨论 `sin x=0`，遗漏 `0、π`。
- 同目标新题：在 `0≤x<2π` 内解 `sin(2x)=-sin x`。标准解为 `{0, 2π/3, π, 4π/3}`。
- 使用 SymPy 1.14.0 分别求出两个区间内完整解集，并对每个候选值代入得到零残差；[计算代码](records/check_math.py) · [计算记录](records/math-check.json)。这只核对本次题目的解集，不自动证明全部模型解释或课件内容正确。

- **正解优化**：先诊断当前过程正确，再交 Solution Refiner；首次优化输出的外层结构门退出码为 1，有限修正后结构门、措辞审计和交接门均为 0，最终给出等价链、正弦相等通法与图象解释三个方向。[截图](screenshots/25-真实模型正解优化.png) · [日志](records/extra-refine.txt)

## 发现的问题与建议

1. **新建练习异步覆盖输入**：点击“新建练习”后立即切换为草稿模式并输入文字，待新会话初始化完成，模式被重置为过程检查，草稿内容被清空。实际自动化中出现过一次；随后对新建请求施加 1.4 秒受控延迟再次复现。建议在创建完成前禁用输入，或保留并合并创建期间的编辑。[复现截图](screenshots/26-新建练习异步覆盖复现.png) · [首次现象](records/extra-draft.txt) · [受控复现](records/extra-new-session-race.txt)
2. **答案暴露粒度不足**：首次“过程检查”反馈直接给出了完整解集，但帮助日志将该反馈记作 `feedback_available`；之后修订只显示“在已记录帮助后提交”，不能进一步识别该反馈已展示完整答案。系统没有把原题修订算作独立复核，但教师无法从条件标签区分提示与完整解集暴露。建议为反馈实际包含完整答案的情况提供明确标记，并避免把自动识别结果当成百分之百可靠的阅读记录。[诊断截图](screenshots/05-真实模型诊断.png) · [后续条件](screenshots/14b-重试后修订成功.png)
3. **调用稳定性**：草稿分析、大纲生成各有一次超时，学生修订有一次模型调用失败；三项均通过任务中心手动继续完成。现场查询在修订首次失败时显示 `diagnostic.category=rate_limit`；重试覆盖了该提交的当前结果，但原始失败截图、日志及任务事件仍保留。建议在界面中更明确显示失败类别与可继续状态，并保留重试前诊断元数据。
4. **细节表达**：正解优化界面在本次输出中将“本解答尚未展示”前缀重复显示了一次。建议在呈现卡片时避免与模型返回文字重复。[截图](screenshots/25-真实模型正解优化.png)
