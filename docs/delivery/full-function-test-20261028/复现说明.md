## 当前浏览器交互

本次环境为 Python 3.12.6、Node.js v26.7.0、Playwright CLI 0.1.22。浏览器用本机默认 Chromium；截图尺寸与具体交互见四份原始输出。先在独立终端启动**测试替身服务**：

```bash
python3 app/tests/browser/serve_fixture.py --port 8767
```

该服务运行真实工作台和独立临时数据库，替换模型推理，不调用真实模型。运行以下脚本（需要Node/npm与可用浏览器）：

```python
from pathlib import Path
import subprocess

cli = ["npx", "--yes", "--package", "@playwright/cli@0.1.22",
       "playwright-cli", "--session", "math-function-replay"]
subprocess.run(cli + ["open", "http://127.0.0.1:8767/"], check=True)
try:
    for name in ["teaching_loop", "learning_path", "math_widgets", "glass_ui"]:
        source = Path("app/tests/browser") / (name + ".js")
        result = subprocess.run(cli + ["run-code", source.read_text(encoding="utf-8")],
                                capture_output=True, text=True, timeout=180)
        output = result.stdout + result.stderr
        print(name, output)
        assert result.returncode == 0 and "### Error" not in output
        assert '"passed":true' in output.replace(" ", "")
finally:
    subprocess.run(cli + ["close"], check=False)
```

本次为避免占用已有服务，使用18767端口，将相同源码中的8767地址替换为18767后执行。截图输出到 `output/playwright/`；本次9张截图另存公开记录的 `current/browser/screenshots/`。请不要把这些替身测试当作真实模型行为验证。
