# 图片草稿的入口流程（两条流）

`draft_source` 是 `image_description` 时读这一份。核心是把两件事拆开，并且不许互相越界：

| 流 | 干什么 | 靠什么 | 不许干什么 |
| --- | --- | --- | --- |
| **内容流** | 知道纸上**写了什么** | **学生自己写下来 / 口述的文字** | 不许自己用视觉读字符 |
| **版面流** | 看出**长什么样**：分了几块、哪处被划掉、旁边补了什么、有没有图形、行序与密度 | **自己看图** | 不许据版面观察断言某个字符是什么 |

两条流**平行进行、分开陈述**。本技能只看版面习惯，不判断计算对错；内容流主要是为了知道哪块属于哪道题、以及读懂学生的版面描述。

## 一、内容流：只能来自学生

**本项目不含任何转写（OCR）技能。** 手写照片的**内容**只有一个合法来源：
**学生自己把纸上的东西写下来或说出来**。他给的这份文字就是 `image_description` 的内容，
`audit --draft` 传的是它，不是你复述的版本。

三条硬约束：

1. **不许自己用视觉读字符。** 读错一个数字，就会让整张卡的版面描述对不上纸面。
2. **不许把"我看了两遍"当成验证。** 你自己看图读出来的内容，与你自己出的卡同源，等于自己给自己作证。
3. **没有学生的文字描述就停，不许兜底。** 学生在线 → 请他打字或口述；不在线、但版面看得清 → 只出版面能支撑的习惯卡（见第五条）。**任何情况下都不要"我先估着读"。**

## 二、版面流：自己看图，只判几何与痕迹

版面**不是**文字识别，可以也必须自己看。要产出的是：

- **分区**：纸上有几块？块与块之间有没有分隔（横线、留白、题号）？哪块属于哪道题？
- **划改**：哪一处被划掉？划线之后旁边补写了没有？补写的大致是几个字？有没有反复涂改？
- **图形**：有没有画图？标了什么？画在计算的哪一步之前还是之后？
- **行序与密度**：一行一步还是挤在一起？有没有大段空白跳过去？
- **留白**：哪里空着？有没有像检验区的位置？

**唯一越界的是内容**：可以写「第 3 行被划掉，旁边补写了一小段」，**不能**写「第 3 行原来写的是 x=1，改成了 x=±1」——后半句是内容，必须来自内容流。

## 三、核对：念给学生确认的是"写了什么"

把**内容全文**念给学生核对，尤其是划改与分区这两块。核对不是让他判对错，是让他确认**你手上的和他写的是同一个东西**。

**"看起来读得清"不等于读清了。** 最危险的错不是"我看不清这个字"，而是**我以为我看清了**。所以核对要念的是**全文**，不是只念"我不确定的那些"。

## 四、易混记号：只写进 scope，不据此下版面结论

手写里形近的字（`≤`/`<`、`±`/`+`、`6`/`8`、`1`/`7`、小数点与上标位置）**不要自己判读**。
如果这些记号影响你对版面的判断（例如"这一块是不是另一条路径"），把它写进 `scope` 的未核对项，请学生确认：

> 「右边那一段我没读字符，只看到它和左边有留白隔开；请你确认它是同一道题的第二问，还是另一道题。」

## 五、降级矩阵

| 情形 | 怎么办 |
| --- | --- |
| 学生给了文字描述，图也清楚 | 正常走：内容流 + 版面流 + 核对 → 出完整卡片 |
| 学生没给文字描述 | **停在内容流**：不许自读字符。学生在线 → 请他打字 / 口述 / 重拍；不在线 → 只出版面能支撑的习惯卡（下一条） |
| 图太模糊 / 反光 / 整片认不出 | `refuse --reason unreadable`，不要硬猜 |
| 局部认不出（如某一段反光） | 认得出多少写多少；认不出的那几处**逐处点名**写进 `scope` |
| 题号 / 分块归属定不下来 | 按 SKILL.md「分块确认不了时」：只做整张纸层面的版面观察，`scope` 写明边界未确认 |
| 学生只问「这张纸做了几道题」 | 走 `partition` 出口（见 [partition.md](partition.md)）：只看版面分块，给估计范围，请学生确认归属 |

## 六、只出版面维度的习惯卡（不是降级）

学生没给文字描述、但版面看得清时，习惯分析仍可成立——这本来就是本技能的主产品，不是"降级卡"。三条要求：

1. **交付时明说**：本卡的内容未经学生文字确认，**只看版面**；
2. `scope` 写明"内容未经确认、只看了版面"；
3. 六维里**只给版面能支撑的那几维**：分区与边距、划改与自纠、图形与标注可以给；步骤分行与密度、多路径标记、留白与检验区看不出来就标 `不适用` 并写明原因，**不许为凑齐六维硬评**。

## 七、交卡前的自检

- [ ] 卡片里没有任何"算错 / 错在 / 写错"的判断。
- [ ] 版面类结论（分区、划改、图形、留白）与内容类信息（式子、数字）在文字里能分清来源。
- [ ] `scope` 里写明了：内容来自谁、哪些地方没看清、只看了哪些维度。
- [ ] 交付给学生的话里**没有**把"我只看了版面"说成"我检查过了"。
