# 题目分区（`partition` 出口）

学生把**一整张草稿纸**发过来，问「我这张纸大概做了几道题」时，走这个出口。

**它只做版面分块，不读字符。** 能看的只有：块与块之间的留白、分隔线、栏位、
区域大小、书写方向、边缘处有没有题号标记、哪一块被划掉或另起一段。
**不能**读「这行写的是 x=2」——那需要学生自己给出文字。

## 核心区分：版面块 ≠ 题目

- 一个版面块可能是：一道题、一道题的一问、同一题换方法的第二次尝试、或一段废弃草稿。
- 两个相邻块之间只有一行空隙时，**不要硬判成两道题**；把它标成低置信，写进 `uncertainty`。
- 输出给**范围**（`count_range`），不要只给一个数；估计值必须落在范围内。
- 块数、估计数、范围都要 ≤ 版面块数。

## 流程

1. **看版面**：按空间位置切块，逐块写位置（左上 / 右上 / 中部 / 下方）、
   视觉依据（留白、分隔线、栏位、书写方向）、像不像一次独立尝试。
2. **估数量**：给出 `estimated_problem_count` 与 `count_range`，并写清哪里分不准。
3. **写确认问题**：把「我大致看到几块、像几道题、哪两块可能是一道」问回学生。
   **学生确认之前的归属只是候选。**
4. **过门**：

   ```bash
   python3 scripts/partition_check.py validate --payload partition.json --strict
   ```

   退出码：0 通过 · 1 不合格（块数/范围/措辞/边界）· 2 输入非法。
5. **交付**：把分块单翻译成教学语言（不要直接甩 JSON），明说「这是版面块数，不是题目数」；
   把块列给学生，请他确认归属。
6. **确认之后**：每一块要单独分析时，请学生把**那一块的内容**打成文字；
   再用那一块作为 `--draft` 走正常的六维分析。**分区单本身不产六维卡，也不查错。**

## 分块单字段

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `action` | string | 固定 `"partition"` |
| `block_source` | string | `image_layout`（看照片版面）或 `student_text`（学生文字里的布局描述） |
| `blocks` | object[] | 1–12 块，每块六个字段 |
| `estimated_problem_count` | int | 1 ≤ 估计值 ≤ 块数 |
| `count_range` | int[2] | `[最少, 最多]`，1 ≤ 最少 ≤ 估计值 ≤ 最多 ≤ 块数 |
| `uncertainty` | string | 非空：哪里分不准、为什么 |
| `confirmation_question` | string | 非空，必须是一个问句或含「确认 / 像不像 / 哪」 |
| `limitations` | string[] | 至少一条，含「版面 / 不读字符 / 块数不等于题目数 / 归属需确认」之类的说明 |

每块六个字段：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `block_id` | string | 非空、唯一，如 `B1` |
| `location` | string | 非空，版面位置 |
| `visual_cues` | string | 非空，为什么把它当成一块 |
| `separate_problem` | bool | 像不像一次独立的题目尝试；拿不准写 `false` |
| `confidence` | string | `高` / `中` / `低` |
| `note` | string | 非空，与相邻块的关系或分不准的原因 |

## 硬约束

- **不许读字符**：不得写「我看出来这行写的是…」「识别出…”；内容只能来自学生。
- **不许断言**：「就是 3 道题」「已经分好了」「毫无疑问」都会被 `E_ASSERTIVE_PARTITION` 拦下。
- **不许查错**：分区单不写「算错 / 错在 / 写错」；要查对错请走 `math-error-diagnosis`。
- **不许产六维卡**：`dimensions`、`top_3_habits`、`error_check` 等字段出现即 `E_EXTRA_FIELD`。
- **块数不等于题目数**；`confirmation_question` 与 `limitations` 是必需字段，不是客套。

## 能力边界

门脚本只查分块单的形状与措辞：**它不判断分块是否真的对应题目，也不验证图片**。
学生确认之前的归属只是候选；确认之后的归属才是分析依据。
