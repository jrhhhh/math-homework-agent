# 六维版面习惯规则

本文展开 [`SKILL.md`](../SKILL.md) 的六维评分尺度、学段适配与整张纸分块。**规则以 `SKILL.md` 为准**；
机器可读常量（维度键名、评分取值、学段表）以 [`scripts/_rules.py`](../scripts/_rules.py) 为准。

**本技能只看版面，不判断计算对错，也不读字符。** 六维评分是**观察的结论，不是配齐的配额**：
观察不到就标「不适用」并写明原因，不要硬给分数。

## 通用约定

- `score` 取 高 / 中 / 低 / 不适用。
- `observation` 一句话观察；`evidence` 点名版面位置或痕迹；`risk` 只能是「若…可能…」的假设句。
- **六个维度都要逐维看**；确实观察不到时写「不适用」并说明原因。
- 肯定积极信号：划掉后能自我纠正、有标号区分多条路径、画图时机对、留出检验区，都要写出来。
- `scope` 写明看了什么、没看什么；缺原题、照片内容未经确认都要写进去。

## 1. organization 分区与边距

| 评分 | 尺度 |
| --- | --- |
| 高 | 分区清楚，有边距或分隔线；不同步骤/不同小问各有位置；能按区域追溯 |
| 中 | 有基本顺序，但区域靠位置区分，没有标号或边距线；内容多时容易混 |
| 低 | 整页挤在一起，没有分区；不同步骤互相穿插 |

观察点：有没有题号/分块、已知/求/推导是否分开、多题是否混写；有没有留白分隔或折格。
**不要求横平竖直，也不要求边缘留出标准边距**；只要求题与题、步骤与结果能分开。
积极信号：主动折纸分区、给每块写小标题或题号。

## 2. skipping 步骤分行与密度

| 评分 | 尺度 |
| --- | --- |
| 高 | 每一步单独占一行，行距均匀；需要补写时有空间 |
| 中 | 大部分步骤分行，个别几行挤在一起 |
| 低 | 多步挤在同一行（例如连续用等号串起来），行距过密，没有补写空间 |

观察点：一行里有几个等号/箭头；**高风险步骤（移项变号、去括号、开方、分类边界、代入）**有没有独立落点；结果和过程有没有挤在同一行。
**不要求每步都写**：低风险步骤可以心算，草稿允许省略。
注意：**这是版面判断，不是「跳步」的数学判断**——本技能不知道中间少没少步骤，只说哪几步没有落笔空间。

## 3. correction_pattern 划改与自纠

| 评分 | 尺度 |
| --- | --- |
| 高 | 划改少而清楚；划掉后另起一行补写；改处能看出改了什么 |
| 中 | 有划改，补写在旁边但比较挤；或者划改较多但没有影响辨认 |
| 低 | 划改压在原行内部，旧值和新值叠在一起；大面积涂黑，辨认困难 |

观察点：划痕位置、补写在哪、划掉后有没有另起一行、**旧值有没有明确作废**、有没有留原因。
**不要求重抄整页**；只要求旧值和新值能分清。
积极信号：划掉后立刻补写、在改处标注原因（如「符号错」）。
**划改状态**：划线 + 补写 = 已自我纠正；划线 + 没补写 = 放弃的备选路径；划线后仍沿用旧值 = 旧值仍在使用。三种都只作版面观察，**不要判断对错**。

## 4. trial_and_error 多路径标记

| 评分 | 尺度 |
| --- | --- |
| 高 | 有多条路径，用方法①/②、箭头、编号或分栏明确区分；废弃路径有标记 |
| 中 | 有多条路径，但区分只靠位置，容易看混 |
| 低 | 只有一条路径，或第二条路没有标号、和第一条混在一起 |

观察点：分类讨论/多解/多方法有没有编号、箭头或分栏；废弃路径是否划掉或另起一块。
**不要求分栏或排版整齐**，只要求不同分支/路径能区分。
注意：**只看有没有标记**，不判断哪条路径对。

## 5. graphic_use 图形与标注

| 评分 | 尺度 |
| --- | --- |
| 高 | 有图形，顶点/坐标/辅助线/关键点标注完整；图形和算式分开 |
| 中 | 有图形，但标注不全，或图形挤在算式中间 |
| 低 | 纸面没有图形；或只有无法辨认的草图 |

观察点：几何图有没有标顶点、辅助线、交点；函数图有没有坐标轴、极值点；图形放在哪、有没有和算式混在一起。
**不要求画得漂亮**，只要求关键点可认。
注意：**不判断「该不该画图」**——那需要原题和数学判断；只描述纸面上有没有、标注怎么样。

## 6. draft_to_solution 留白与检验区

| 评分 | 尺度 |
| --- | --- |
| 高 | 纸面留出明确的空白/检验区；结果和检验分开写 |
| 中 | 有留白，但没有标出用途；结果旁边有空间 |
| 低 | 纸面写满，结果挤在末尾，没有地方代回检验 |

观察点：有没有留出检验区；答句、单位、范围有没有固定落点；结果附近有没有空间。
**不要求专门划区**，只要求有地方写检验、答句能一眼找到。
注意：**不看最终解答**，只看纸面有没有留出这些位置。

## 中学生常见的版面习惯风险（不要求工整）

先记住：**草稿不是答卷。** 允许简写、箭头、缩写、低风险步骤心算；允许涂改、允许区域不规则。
下面这些不是“不工整”，而是会让学生自己回头找不到、抄错、漏情况的高风险习惯。

| 习惯 | 版面表现 | 风险 | 不要求 |
| --- | --- | --- | --- |
| 多题混写 | 不写题号、几道题挤在同一区域 | 抄错答案、把甲题条件用到乙题 | 不要求横平竖直，只要求题与题能分开 |
| 条件与推导混写 | 题目条件、图形、推导挤在同一块，没有“已知/求”的落点 | 抄错条件、看错题 | 不要求抄题，只要求条件有独立落点 |
| 结果写在纸边/题缝 | 答句、结果挤在页边、题缝或背面 | 抄答时漏掉、被裁掉 | 不要求框起来，只要求结果能一眼找到 |
| 高风险步骤挤一行 | 移项变号、去括号、开方、分类边界、代入与上下步挤在一起 | 出错了定位不到哪一步 | 不要求每步都写；只要求高风险步骤有独立落点 |
| 分类讨论不标号 | 多个分支并排或上下排列，没有 ①②、箭头或分栏 | 漏情况、把不同分支的结论混用 | 不要求排版整齐，只要求分支可区分 |
| 旧值新值叠在一起 | 划痕上直接改写、旧值没划掉或没作废 | 回头把旧值当成结果抄走 | 不要求重抄整页，只要求旧值明确作废 |
| 几何图不标关键点 | 有图，但顶点、辅助线、交点没标 | 看不出对应关系 | 不要求画得漂亮，只要求关键点可认 |
| 结果旁没有检验区 | 答句、单位、范围挤在推导末尾 | 结果错了没发现，抄答时漏单位/范围 | 不要求专门划区，只要求有固定落点 |
| 多路径不区分 | 两条方法写在一起，没有标号 | 两条路的结果混用 | 不要求分栏，只要求标号或箭头 |

### 评分时的三条硬边界

- **不评“工整/美观”**；只评“可追溯、可复核、可区分”。
- **不要求每步都写**；低风险步骤可以心算，高风险步骤才要求落行。
- **不因为涂改多就判低**；看改后是否可辨、旧值是否作废。

### 例：乱但可追溯，仍然可以给高分

纸面很乱、箭头多、字迹不工整，但：题号写在左上；分类讨论用 ①② 标在行首；划掉的一行旁边另起一行重写，旧值明确作废；几何图在右边且标了顶点；右下角留了空白写代回。
→ 分区、划改、多路径、图形、留白都可以给中或高；只有“高风险步骤挤在同一行”那一维可以标低。

反过来，纸面很整齐但没有题号、分支没标、旧值和新值叠在一起 → **不能因为工整就给高分**。

## 学段适配

学段切换的是**用词，不是结构**——六个维度的骨架在任何学段都一样。

| 学段 | 语言风格 | 训练动作 | 重点维度 |
| --- | --- | --- | --- |
| 小学 | 简单、具体、像口令 | 折纸分区、每步落笔、画图 | 分区与边距、步骤分行 |
| 初中 | 清晰、鼓励、可操作 | 草稿标号、改错留因 | 步骤分行、划改与自纠 |
| 高中 | 简洁、策略导向 | 先画图再算、多路径标号 | 图形与标注、多路径标记 |
| 大学 | 平等、元认知导向 | 探索路径标注、草稿即检查 | 留白与检验区、分区与边距 |

小学/初中不该出现「元认知 / 策略导向 / 路径标注 / 方法比较」这类措辞，否则审计报 `W_GRADE_MISMATCH`。默认高中学段。

## 整张草稿纸：先分块，再逐题分析

现实里的草稿纸又乱又多题。整张发过来可以，但**分块必须是显式的一步，而且分完要让学生确认**。

1. **分块**——按空间位置把整张纸切成若干块，逐块写位置与版面依据。
2. **归属**——给每块标上属于哪道题。**没有题号、没有明显边界的，不要硬认。**
3. **核对**——把「这块是第几题」念给学生确认。**这一步没做完不许往下走。**
4. **逐题出卡**——一块一道题一张卡。过门时 `--draft` 传**那一块**的内容。

学生只问「大概做了几道题」时，走 `partition` 出口（见 [partition.md](partition.md)）；不要直接产六维卡。

`audit` 会对草稿里出现两个以上题号标记的情况报 `W_MULTI_PROBLEM_DRAFT`（只认 `第一题`、`（2）`、`①`、段落起首的 `1、` 这类题号，不认 `f(1)=-2` 这样的函数记号）。

### 分块确认不了时

- **不受影响**：分区与边距、划改与自纠、图形与标注（整张纸层面仍可观察）。
- **收缩到连续区域内部**：步骤分行与密度、多路径标记。
- **最不可靠**：多路径标记——分不清「同一题的另一条路」和「另一道题」。
- 出的卡要明说「本卡题目边界未确认」，并在 `scope` 里写清。

## 草稿太简略时

只有几个孤立的数字、没有目标时，**先问一句，或者退 `refuse`**；不要为了凑满六个维度硬给评分。
确实只能看版面的，标「不适用」并写明原因。
