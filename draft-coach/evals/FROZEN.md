# 已冻结：这是「查错版」draft-coach 的基准

**这份基准测的是 2026-10-15 以前的 draft-coach：以“先查计算错误”为主产品。**
2026-10-17 起，draft-coach 已改为**纯版面习惯**技能：不判断计算对错、不产 `error_check`、
没有 `triage` 出口。因此本目录里的 `error_check` / `status` / 错误定位指标
**不再对应当前技能**，不要用它给当前技能打分。

保留它的原因：

- 38 个案例、六子集、锚点校验和门层重放仍然记录了那次评测的方法与数据；
- 其中关于“证据必须逐字出现在草稿里”“锚点不能重叠”“空答案拿满分”的教训
  （见 `docs/FINDINGS.md`）对将来做版面习惯基准仍然有用。

**不要**在当前仓库的常规验证里运行 `draft-coach/evals/tests/`。它依赖旧版
`scripts/_rules.py` 的 `error_check`/`status` 常量，和当前门脚本不兼容；
这些测试在 git 历史里有完整版本。

新的版面习惯基准已经建立，见 [`../bench/`](../bench/)：24 条正面能力案例
（六维分析、证据纪律、整页分区、输入形态），自动层重放当前三道门并核对 tool_log，
人工层单独导出。**不要**用本目录给当前技能打分；
本目录只保留旧版查错评测的方法与数据。当前技能的自带门测试在 `draft-coach/tests/`。
