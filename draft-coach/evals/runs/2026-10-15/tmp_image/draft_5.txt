5.（1）2sinB sinA = √3 sinA；2sinB = √3；sinB = √3/2；B = π/3。
（2）A + C = 2π/3；sinA + sinC = sinA + sin(2π/3 − A)；= 3/2 sinA + √3/2 cosA；= √3 sin(A + π/6)。
∵ sinA 为锐（角），圈出 A ∈ (π/6, π/2)；右侧用大括号列出 0 < A < π/2、0 < C < π/2、0 < 2π/3 − A < π/2，推出 π/6 < A < π/2。
π/6 < A + π/6 < 2π/3；√3/2 < sin(A + π/6) ≤ 1；3/2 ≤ √3 sin(A + π/6) ≤ √3。
右侧另起一列，与主链之间没有标号相连：sin 2π/3 cosA − cos 2π/3 sinA；「√3/2 cosA」那一项上方另写并圈出一个记号（内容读不准）。
