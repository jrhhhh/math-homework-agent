# 学习证据汇总

连接学生作答和教师决策。以任务固定原题、学习目标、学生当前提交版本和实际运行结果为依据，保留可回查 ID。它是证据整理技能，不替代 `math-error-diagnosis`。

## 汇总规则

1. 只取每项任务绑定练习的最新提交；题目、学段或来源变了，标记绑定失效，不继承旧正确性。学生修订后，旧诊断只作历史。
2. 分开记录未提交、处理中、运行/结构检查失败、待补充、过程正确、过程有错、论证缺口和仅答案。没有可交付诊断时不生成数学判断。
3. 引用诊断记录中的首错原文和理由，保留 submission ID、revision 和内容版本。不把推测写成学生原文，不将草稿布局推断为知识障碍。
4. 汇总单位是任务项，不是“班级正确率”或长期能力；同一学生多次修改不能当成多个独立样本。明确模型诊断的证据范围。
5. 交给补救教学时仅传目标、题目、当前诊断及必要原文；任务标题、姓名、学号和自由备注不进入匿名教学材料。需要共享时仍由教师核查原题/引文内是否含身份信息。

## 可执行汇总

[scripts/evidence.py](scripts/evidence.py) 是标准库聚合器。输入 JSON 为 `{"items":[{"id":"...","problem":"...","objective":"...","submission":null或提交记录}]}`；提交记录采用工作台 Store 的 `data/state/result/id/revision/version` 字段。运行：

```bash
python3 learning-evidence-bridge/scripts/evidence.py input.json
```

输出逐题状态、分类计数和证据指纹。它只检查绑定与诊断是否可消费，不验证模型数学判断；新的当前版本会改变证据指纹，使旧补救计划失效。


## 帮助条件

每次提交使用提交前已保存的不可变帮助快照，区分未记录系统帮助、提示/活动后作答、已请求完整讲解、旧记录条件不明。后续帮助不改写历史提交条件。教师解释、外部帮助由使用者补记；系统记录的是请求或内容可用，不声称用户已阅读。

普通修订正确不自动成为独立复核。独立复核需关联新题、相同目标与成功标准、当前完整过程诊断正确，且提交前未记录帮助。未记录不代表没有外部帮助；通过只说明本题表现，不证明长期掌握。补救计划必须引用帮助条件，避免把受助修订写成独立完成。
