# LaTeX 排版、编译与交付

## 模板与公式

用 `assets/reference-answer.sty` 作为起点，将该文件复制到交付源码目录，与 `main.tex` 一起交付；使用 `ctexart`、XeLaTeX。系统中文字体不可用时优先用 TeX Live 自带 Fandol 字体。不要为“编译过关”把数学符号替换成英文单词。

正确的公式源：

```latex
令 \(u=x-1\)，则 \(u\in(-1,1)\)，且
\[
 f'(x)=u^2\left(\frac{2}{1-u^2}+3b\right).
\]
因此，当 \(b\ge-\frac23\) 时，……
```

拒绝以下处理：将 `sqrt(3)`、`x^(k+1)`、`alpha`、`pi` 作为最终公式；将 `x²`、`⇒`、`∛` 用 Unicode 文本替代数学 LaTeX；用 `\textasciicircum` 显示幂；将全部推导套进 `\text{...}`；用一批 `\newunicodechar` 给未转换的公式兜底。

- 行内用 `\(...\)`；关键等式用 `\[...\]`，连续等价推导用 `aligned`/`align*`，分情况用 `cases`，矩阵用 `pmatrix`。分式、根式、上下标、向量、集合、条件概率分别使用相应数学命令。
- 用 `\frac`、`\sqrt`、`\sin`、`\ln`、`\mathbb{R}`、`\mid` 和规范括号；集合条件写 `\{x\in\mathbb{R}\mid ...\}`。
- 长公式在等号或关系符处拆行。不要整体缩小到无法阅读，不通过宽松断行或任意裁剪掩盖溢出。
- “因为/所以/由题意”留在正文；显示公式内的短中文用 `\text{...}`。文字、标点与公式形成完整句子。
- 几何图需要时用 TikZ 或清晰的矢量图，数学关系与原题一致；图中文字可读，不拿低清晰度截图作为主要公式。

## 版面

A4，页边距约22mm，正文约11pt。标题层次克制、页眉简洁、页码清晰；无装饰性满页封面。客观题紧凑连续，长题自然分页。采分表用可换页表格，禁止长段推导挤进窄表格。答案用适度加粗或小型强调，不给每行加大边框。

`example/reference-answer-quality/main.tex` 展示基础题、分布列和分式导数题的排版。它只是版式与编译样例，不是整卷交付，也不作为模型成绩。

## 实际编译

```bash
python3 scripts/build_reference_pdf.py /绝对路径/main.tex --output-dir /绝对路径/build
```

脚本实际执行 XeLaTeX 两遍，使用 `-no-shell-escape`，检查日志的缺字、未定义引用、溢出和报错，生成 `build-report.json`。失败则修源文件重跑，不在报告中伪造成功。源码仅使用可信模板和检查过的内容；禁用 shell escape 不等价于完整 TeX 沙箱。外部用户提供的原始 TeX 不应直接在工作台服务器进程中编译。

## 成品检查与交付门槛

编译后使用 PyMuPDF/Poppler 渲染全部页面，至少逐一查看含分式、根式、上下标、多行公式、表格、长题跨页和首尾页的页面；发现缺字、错行、裁切、叠字或过度留白即修正。抽取 PDF 文本可检查题号和遗漏，但无法替代看图。

交付前确认：

- 原卷每题每小问都在覆盖清单中，解答状态真实；所有已知分值分别对齐。
- 无编译错误、缺字、未定义引用及溢出版心；公式已真正排版，正文不用程序表达式充当公式。
- 每个采分点有数学含义；新增分、累计分、小问、题目与整卷总分相符。
- PDF 确实存在且能打开；交付 PDF、`.tex`、样式和必要配图，源码从交付目录能够重新编译。
- 技术日志与质量记录单独保存。未完成数学核验的范围对用户可见，但不在每题重复冗长免责声明。
