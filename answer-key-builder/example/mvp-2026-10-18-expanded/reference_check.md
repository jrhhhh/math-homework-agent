### 1.3 解方程 3/x = x-2

- 参考：x = (1±√13)/2。
- 正确：**x=3 或 x=-1**。
- 依据：
  - x=3：左边 3/3=1，右边 3-2=1；
  - x=-1：左边 3/(-1)=-3，右边 -1-2=-3。
  - 参考的两个根实际满足 x²-x-3=0，不是原方程。代回可见：x≈2.3028 时左边≈1.3028、右边≈0.3028，不相等。

### 1.4 解方程 √(2x+1)=x-1

- 参考：x=2。
- 正确：**x=4**。
- 依据：
  - x=4：左边 √9=3，右边 4-1=3；
  - x=2：左边 √5≈2.236，右边 1，不相等。
  - 平方后得 2x+1=x²-2x+1，即 x²-4x=0，候选 x=0 或 4；由右边非负要求 x≥1，舍去 x=0。

### 1.5 解方程 x/(x-2)+1/(x+2)=8/(x²-4)

- 参考：无解。
- 正确：**x=-5**。
- 依据：x=-5 在定义域 x≠±2 内；左边 (-5)/(-7)+1/(-3)=5/7-1/3=(15-7)/21=8/21，右边 8/(25-4)=8/21，成立。
- 去分母得 x(x+2)+(x-2)=8，即 x²+3x-10=0，根为 x=-5 与 x=2；x=2 是增根，x=-5 保留。

### 2.5 解不等式 (x-1)/(x+2)≥2

- 参考：-2<x≤-5。
- 正确：**-5≤x<-2**，即 [-5,-2)。
- 依据：参考写法上下界颠倒，按字面是空集；应是把端点写反了。
  - x=-5：左边 (-6)/(-3)=2≥2，成立，端点可取；
  - x=-3：左边 (-4)/(-1)=4≥2，成立；
  - x=0：左边 (-1)/2=-1/2≥2，不成立；
  - x=-2 时分母为零，不能取。

### 3.3 等比数列 a₁=2，a₃=8，求 S₅

- 参考：S₅=62。
- 正确：**S₅=62（q=2）或 S₅=22（q=-2）**。
- 依据：a₃=a₁q² 给出 q²=4，q=±2；题目没有限定 q>0。
  - q=2：2,4,8,16,32，和为 62；
  - q=-2：2,-4,8,-16,32，和为 22。
- 若题目本意要求各项为正，需要补充 q>0 或“正项等比数列”的条件。

### 4.2 解不等式 (x-a)(x-2)>0

- 参考：
  - a>2 时，x<a 或 x>2；
  - a=2 时，x≠2；
  - a<2 时，x<a 或 x>2。
- 正确：
  - a>2 时，**x<2 或 x>a**；
  - a=2 时，x≠2；
  - a<2 时，x<a 或 x>2。
- 依据：a>2 时两根为 2 与 a，且 2<a，大于零应取两根之外，即 x<2 或 x>a。参考把 a>2 的情形写成了与 a<2 相同的结论。
- 反例：a=3、x=2.5 时 (2.5-3)(2.5-2)=(-0.5)(0.5)=-0.25<0，不满足原不等式；参考的“x<3 或 x>2”会把 2.5 错误地包含进去。
