# 参考答案编写规范

## 文档组织

使用“试卷名称 + 参考答案与评分建议”为标题。`\papertitle` 的第一个参数只写试卷名称，宏会自动在标题下和页眉补“参考答案与评分建议”。标题下用一行说明适用学段、满分、评分性质及版本；随后直接进入“答案速查”，不默认制作空白占大半页的独立封面。不在每页重复冗长的模型或工程说明。

答案速查只收录客观题题号和结果；解答题摘要可选。多选题明确为多个选项，不把所有题都误标为单选。正文按原卷题型分节、按原题号连续排列，保留全部小问。题面可简要摘录关键条件与所求，配图依赖必须在摘要或解答中说明；除用户要求外不全文复刻长题面。

每题顺序：

1. **题头**：题号、满分（未知则标待确认）；小问分值来源明确。
2. **思路点拨**：1–3句，直接指出切入点与关键转折，如“把面积比化为有向线段比，再由韦达定理消去交点坐标”。不重复题干或使用泛泛励志语言。
3. **参考解答**：按（1）（2）（i）组织。给出关键等式、依据、条件与结论，不机械标注“步骤1、步骤2”拆碎每一行。
4. **评分标记**：解答题在完成关键成果处标记累计分，在解答后附采分表说明每点新增分；二者必须一致。短题可直接列新增分，文首明确口径。不要混用两种口径。
5. **难度评价**：基础/中等/较难，附本题具体依据，如分类个数、突破口或运算量，避免每题套“联系多个条件”。
6. **评分补充**（确有需要时）：等价方法、允许简写、易混条件和待核定事项。常规重复说明放文首一次即可。

选择填空题保持紧凑，通常是点拨、必要解析、答案和难度，不给虚构步骤分。长证明允许跨页，不能将整题装进不可分页盒子；标题与至少两行正文留在同页。题间不强制 `\clearpage`，不把简单题撑成一页。

## 分值的数学设计

先写成立的完整解答，再把它划为可判定的数学成果：建立模型/关系、有效转化、关键推导或分类、完成结论。难点或主要推导承担相称分值，常规整理不因拆行变多而多得分。每个评分点必须描述学生需要写出什么，不能只写“步骤正确”。同一个成果不在相邻条目重复计分。

- 用户给的小问分值必须保留。只给全题分值时，小问与步骤分配均标“建议”；未知分值以“待确认”处理，不默认每题相同满分。
- 用表格列“采分点/新增分/累计分”，逐小问和逐题求和，与原卷题分一致，再核对整卷总分。不能根据步骤数自动均分。
- 正确等价解法按对应数学成果给分。证明题的依据、分类完备和必要条件也是数学成果；不能只给最终结论分。
- 多选部分分、填空分空给分和错误沿用政策以实际规则为准，未知时保留待确认，不能编造官方政策。
- 某题未解决时明确数学状态；只对已可靠成立的部分给临时采分建议，完整评分表不得假装已经建立。

## 数学复核

逐题复核题设和结论，尤其定义域、端点、增根漏根、参数临界值、命题方向、穷尽性和退化图形。读过现成解析的本次制作是“整理与复核”，不能称为盲测或独立模型实验。工具验证要保存真实命令与结果；结构或编译成功不等于数学正确。

正文只保留对阅卷有帮助的核验说明。详细工具记录、覆盖清单和未解决事项放附录或独立验证文件，不把日志塞进每题影响阅读。

## 工作台在线文本

在线回复也按题型/题号/小问组织，用标准数学分隔符渲染表达式；正文应能独立阅读，不靠展开 JSON 才看到解答。完整文件交付另遵循 LaTeX 规范，不把在线回复“已生成”当成 PDF 导出回执。
